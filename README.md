# Robot Agent Module - Member 2

## Digital Twin for Smart Warehouse Coordination

This module implements autonomous robot agents for warehouse operations, compatible with Member 1's JSON-based environment logging.

## Features

- 🤖 Multiple robot types (Picker, Packer, Charger, Universal)
- 🔋 Battery management and charging behavior
- 🚶 Basic movement with obstacle detection
- 📊 JSON log generation (Member 1 compatible)
- 👥 Multi-robot coordination
- 📈 Performance tracking
